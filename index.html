Installation

Get Veltrix on Android

Sideloading takes under a minute. Follow these steps after your download finishes.

1

Download the APK

Tap the download button above. The file (Veltrix.apk) saves to your device's Downloads folder.

2

Allow installs from this source

Open the downloaded file. If Android asks for permission to install unknown apps, tap Settings and turn the toggle on for your browser or file manager.

3

Tap Install

Return to the install prompt and tap Install. This usually finishes in a few seconds.

4

Open Veltrix

Tap Open and sign in to enter your first tournament.

Seeing a "harmful app" or Play Protect warning?

This appears because Veltrix is installed outside the Play Store, not because anything is wrong. It's expected for every app distributed this way. Tap Install anyway or More details → Install anyway to continue.
